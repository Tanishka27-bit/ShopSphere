# 🛍️ ShopSphere – E-Commerce Web Application

ShopSphere is a Java-based e-commerce web application that allows users to explore products, manage their shopping cart, and view their orders. It also provides an admin panel to manage users, products, categories, and orders.

## 🚀 Features

* User Registration and Login
* Product Browsing
* Shopping Cart Management
* Order History
* Admin Dashboard
* User, Product, Category, and Order Management
* MySQL Database Integration

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JSP
* **Backend:** Java
* **Database:** MySQL
* **Server:** Apache Tomcat
* **Build Tool:** Maven
